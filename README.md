# Fortune Cookie Wisdom for Developers

This repository contains a lightweight Node 22 program that writes a single original fortune-cookie line for a software developer to entry.txt in a deterministic manner without network access or external dependencies. Distilling complex engineering philosophy into a single punchy sentence ensures maximum conceptual impact with zero bloat.

## How to run

To generate the fortune-cookie wisdom file, run:

```bash
node main.ts
```

You can optionally set the `MAKEFUN_OUTPUT_DIR` environment variable to choose the output directory where `entry.txt` will be written:

```bash
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
